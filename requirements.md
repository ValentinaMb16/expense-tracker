# Expense Tracker - Requirements

## Project Description

Expense Tracker is a web application that allows users to manage their personal income and expenses.

## Project Goal

The goal of this project is to practice backend development using C#, ASP.NET Core, SQL Server and Entity Framework Core.

## MVP

The first version of the application will allow users to manage their personal transactions.

## Functional Requirements

### Categories

- Create a category.
- View categories.
- Update a category.
- Delete a category.

### Transactions

- Create an income.
- Create an expense.
- View transactions.
- Update a transaction.
- Delete a transaction.

### Dashboard

- View total income.
- View total expenses.
- View current balance.

## Technologies

- C#
- ASP.NET Core Web API
- .NET 8
- SQL Server
- Entity Framework Core
- OpenAPI
